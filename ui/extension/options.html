Send to Ledger

The address you open Ledger at in this browser, e.g. http://ledger.local:8080 or https://ledger.example.com. The browser asks once to let the extension reach that address, and only that address.

How it works

  • Right-click a download link on your bank's or a supplier's site and choose Send to Ledger…. The file is downloaded with that site's login and goes straight to Ledger, without being saved to your computer.
  • Or click the toolbar button and drop a file you already have.
  • By default files land in the Downloads module's inbox in Ledger, where you send them on, download, archive or delete them. With the Auto sort module installed you can also send statements (CSV, OFX, QFX, QBO) and bills (PDF, EML) straight there. CSV files can go to Ledger's own journal import.
  • It uses your Ledger login in this browser; log in to Ledger as usual. The extension stores only the address above, never a password. Requests to Ledger are made from a Ledger tab (a hidden one is opened and closed if none is open), so Ledger's protections stay on.
