Import is now part of Auto sort

Everything Import did (the inbox for files, email, the scanner, the camera, the browser extension and the phone app) now lives in the Auto sort module. This last version of Import takes nothing in any more. It keeps the files it holds safe in Ledger's Documents until Auto sort has brought them over.

What to do

  1. Update Auto sort to 0.17.0 or newer

    Under Settings → Modules, press Update modules now.

  2. Open Auto sort and press “Bring over Import's files”

    An admin does this, once in each organization. Auto sort takes over the inbox, what the email check has seen and learned, and the AI extractions. Nothing is deleted from Import.

    Open Auto sort
  3. Remove Import

    Under Settings → Modules, once every organization has brought its files over. Removing a module keeps its data.

    Open Settings → Modules

Browser extension and phone app

The Send to Ledger extension and the Android app that came with Import no longer reach it. Install the new ones from the Auto sort page; they send files straight to Auto sort.
